# Skyluna's Personal Site

A minimal personal website built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

## Tech Stack

- Astro
- Tailwind CSS v4
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

The dev server will start at `localhost:4321`.

## Build

```bash
npm run build
```

The production site will be generated in `./dist/`.
